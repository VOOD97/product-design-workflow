# Задача
Проверь UX формы приглашения сотрудников. Роль — администратор, задача — отправить приглашения и понять результат. Контракт: до отправки видны адреса и роли; в случае частичного успеха UI показывает число успешных/неуспешных, список ошибок и Retry только для неуспешных. Термины «приглашён» и «отправлено» не означают подтверждённую регистрацию сотрудника.
Предоставлены только учебные текстовые наблюдения. URL работающего прототипа нет, Playwright/браузерный прогон недоступен. Ничего продуктового менять не нужно. Самостоятельные действия пока выполнить невозможно: оценить предоставленное, явно назвать ограничения и что воспроизводить после появления браузера.
