# Настройка FigJam MCP и проверка доступа

Применяй этот справочник только при выбранном формате `document+figjam`. Для `document` и `document+local` FigJam имеет статус `not-required`, настройки и проверки MCP — N/A и не снижают готовность модели.

Для создания FigJam board нужен подключённый MCP с подтверждёнными операциями для FigJam, авторизованный аккаунт и право записи. Чтение макетов Figma Design само по себе этого не обеспечивает.

## Что проверить до запуска

1. Найди актуальную официальную инструкцию выбранного MCP и поддерживаемого клиента. Установка сервера/интеграции и подключение MCP к Claude Code, Codex или Cursor выполняются по инструкции для конкретного клиента.
2. Проверь текущий набор tools/capabilities: действительно ли он создаёт FigJam-диаграммы или читает/пишет FigJam-файлы. Названия tools и их аргументы бери из реального описания подключённого сервера, а не из памяти.
3. Пройди авторизацию поддерживаемым способом, не копируя токены/пароли в `flow.md` или переписку.
4. Определи целевой board/file и доступ аккаунта. Для обновления существующего board нужно право записи; наличие URL или view-access недостаточно.
5. Проверь, где создаётся результат, возвращается ли постоянная ссылка на FigJam, сохраняется ли диаграмма и доступно ли чтение/preview для проверки.
6. Проверь ограничения размеров, Mermaid-синтаксиса, типов узлов и операций; при больших моделях разбей диаграммы на секции.

## Правило выполнения

Не придумывай npm-пакеты, команды установки, endpoint, tool names или конфигурационные ключи. Используй инструкции поставщика и фактический интерфейс MCP. Если окружение поддерживает только часть операций, перечисли эту часть. При отсутствии подтверждённой записи оставь `FigJam status: pending` и дай точное условие завершения.

## Критерий успешного создания

Нужны: существующий сохранённый FigJam board, постоянная ссылка/идентификатор, корректные ID и ветви, проверка соответствия `flow.md`. Успешная генерация изображения или временной диаграммы не равна этому результату. Не изменяй права доступа и не публикуй board автоматически.

## Источники для актуальной настройки

Официальные источники и подтверждённые операции конкретного сервера должны быть проверены при установке и запуске. Команды разных клиентов не взаимозаменяемы. Этот справочник намеренно не фиксирует неподтверждённый сторонний пакет.

## Проверенный официальный вариант (2026-10-12)

FigJam поддерживается официальным **Figma MCP**. В Claude Code подключение возможно через официальный plugin или вручную:

```bash
claude mcp add --transport http figma https://mcp.figma.com/mcp
```

Затем открыть `/mcp`, выбрать figma и пройти OAuth. Это инструкция настройки, не уже выполненное подключение. Проверить tools фактически доступного сервера. `generate_diagram` создаёт FigJam-диаграммы из Mermaid/описания; `use_figma` предоставляет операции с содержимым FigJam при поддерживаемом клиенте и разрешениях. Для изменения существующего файла проверить write-access и целевой file/board. Не путать read-only подключение с созданием board.

Источники: [настройка remote MCP](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/), [инструменты и prompts](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/). Для Codex/Cursor использовать раздел настройки их клиента в той же документации; команды Claude Code не копировать в другой клиент. После обновлений документации/сервера сверить доступные operations заново.
