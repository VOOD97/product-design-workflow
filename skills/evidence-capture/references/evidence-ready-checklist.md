# Gate: Evidence Ready

PASS: все обязательные требования выполнены на одной revision. LIMITED: только необязательные дополнительные проверки не выполнены и это явно ограничивает оценку; обязательная матрица полна. FAIL: любой обязательный пробел или недостоверное заявление. Автоматическое ревью допустимо только при PASS обязательной части; открытый блокер нельзя заменить N/A.
